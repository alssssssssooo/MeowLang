# MeowPy Frontend Compiler

`tools/meowc.py` is an optional Python-style frontend. It compiles readable
`.meow` source into MeowLang `.docx` programs. The runtime is still
`native/meow` (C11); Java, Python, and any interpreter runtime are not required
at execution time.

Raw MeowLang programs require adjusting the color, italic, underline, font, and
font size of every symbol in Word. This frontend automates those formatting
details so programs can be written with ordinary indentation and keywords.

## Quick start

```bash
# Compile
python3 tools/meowc.py examples/game2048.meow -o game2048.docx

# Run
./native/meow game2048.docx
```

Without `-o`, the output uses the source name with a `.docx` extension:

```bash
python3 tools/meowc.py examples/hello.meow
./native/meow examples/hello.docx
```

## Readable output: the Meow cipher

Built-ins are written as two-syllable meow code words (`喵喵`, `喵嗚`,
`嗚喵`, `嗚嗚`) whose color, bold, double underline, and highlight encode
the symbol. Any Word installation reads the generated DOCX directly — no
fonts are needed. See the cipher legend in the top-level `README.md` and the
shared specification in `tools/meow_cipher.py`.

The legacy `Meow-*` symbol fonts (`fonts/`, optional) only apply to older,
font-encoded DOCX files:

```bash
sh fonts/install-fonts.sh --user
```

For debugging, dump the frontend AST or the generated runtime expressions:

```bash
python3 tools/meowc.py examples/hello.meow --dump-ast
python3 tools/meowc.py examples/hello.meow --dump-runtime
```

## Syntax

Supported Python-style syntax:

```python
# Variables and assignment
x = 10
x += 1
items = [1, 2, 3]
items[0] = 9

# Arithmetic and comparisons
print(1 + 2, 7 // 2, 7 % 3, 2 ** 10)
print(x > 5 and x < 100)
print(3 in items)

# Conditionals
if x > 10:
    print("big")
elif x == 10:
    print("ten")
else:
    print("small")

# Loops
i = 0
while i < 5:
    print(i)
    i += 1

for n in range(1, 6):
    print(n)

for ch in "meow":
    print(ch)

# Functions and early return
def fact(n):
    if n <= 1:
        return 1
    return n * fact(n - 1)

print(fact(6))

# Lists and strings
a = [1, 2, 3]
a.append(4)
print(a[0], a[-1], a[1:3], len(a))
print(str(123) + "!", int("42") + 1)

# Conditional expression
print("yes" if 3 > 2 else "no")
```

### Name mapping

To keep the runtime small, the frontend maps some Python names to native
built-in functions:

| Python syntax | Runtime symbol | Notes |
| --- | --- | --- |
| `print(...)` | `println` | Space-separated arguments, then a newline |
| `input(prompt)` | `readline` | Reads one line from standard input |
| `int(text)` | `parseInt` | Decimal integer string to integer |
| `a.append(x)` | `push` | Appends to a list in place |
| `a.pop()` | `pop` | Removes and returns the last element |
| `x in a` | `contains(a, x)` | List membership or substring test |

`/` and `//` both perform integer division rounded toward negative infinity.
This language currently has no floating-point numbers.

### Not supported yet

- `break`, `continue`, and loop `else`
- Classes, exceptions, and `with`
- Keyword arguments, default arguments, and variadic arguments
- `not in`, `is`, and chained comparisons such as `a < b < c`
- Floating-point numbers and f-strings
- In-place list methods such as `extend`, `insert`, and `remove`
- String methods such as `.upper()` and `.lower()`

Use raw Meow syntax, or extend `native/meow.c` and `tools/meowc.py`, when these
features are needed.

## Encoding

The compiled DOCX is still a valid MeowLang program; its formatting is simply
generated by code:

- **Variables**: a unique color from a reserved palette, with no italic,
  underline, or font.
- **Function calls and argument lists**: italic `喵` as brackets, with grayscale
  colors based on nesting depth.
- **Text literals**: a purple (`0x7030A0`) single-underlined `喵` pair around the
  content; the content itself is black.
- **Built-in symbols**: a Meow-cipher code word (`喵喵`/`喵嗚`/`嗚喵`/`嗚嗚`)
  with a reserved combination of color, bold, double underline, and highlight,
  so they cannot collide with user variables and no fonts are required.
- **Integer literals**: compiled as `parseInt("...")` to avoid DOCX font-size
  limits.

The resulting `.docx` still looks like a wall of formatted "meow" symbols in
Word, but the runtime can parse it directly into an expression tree.

## Requirements

The frontend needs Python 3.10 or newer and no external packages. Running the
compiled DOCX requires the native build:

```bash
make -C native
```

Windows build configuration is provided through CMake but has not been tested
on Windows yet. It requires MinGW-w64 or MSVC plus zlib, expat, libpng, and
libjpeg.

## Examples

- `examples/hello.meow`: input and output.
- `examples/test1.meow`: arithmetic, control flow, functions, lists, and
  strings.
- `examples/game2048.meow`: a complete text-mode 2048 game.

2048 controls:

```text
w = up
a = left
s = down
d = right
q = quit
```

# MeowPy 前端編譯器（繁體中文摘要）

`tools/meowc.py` 是可選的 Python 風格前端，把可讀的 `.meow` 原始碼編譯成
MeowLang 的 `.docx`。執行期仍然是 `native/meow`（C11），不需要 Java、Python
或任何直譯器 runtime。

## 快速開始

```bash
python3 tools/meowc.py examples/game2048.meow -o game2048.docx
./native/meow game2048.docx
```

沒有指定 `-o` 時，輸出會與來源同名，副檔名改為 `.docx`。

除錯時可以印出前端 AST 或執行期運算式：

```bash
python3 tools/meowc.py examples/hello.meow --dump-ast
python3 tools/meowc.py examples/hello.meow --dump-runtime
```

## 支援語法

- 變數、指派、複合指派
- 算術：`+`、`-`、`*`、`/`、`//`、`%`、`**`
- 比較與布林：`==`、`!=`、`<`、`<=`、`>`、`>=`、`and`、`or`、`not`
- 條件：`if`、`elif`、`else`
- 迴圈：`while`、對列表與文字使用 `for`
- 函式：`def`、遞迴、提前 `return`
- 列表：常值、索引、負索引、切片、`append`、`pop`、`len`
- 字串：`str`、`int`、`in`、串接
- 三元運算式：`a if cond else b`

`/` 與 `//` 都是整數除法，向負無限方向取整；目前沒有浮點數。

## 尚未支援

- `break`、`continue`、迴圈的 `else`
- 類別、例外處理、`with`
- 關鍵字參數、預設參數、可變參數
- `not in`、`is`、比較串接
- 浮點數、f-string
- `extend`、`insert`、`remove` 等就地列表方法
- 字串的 `.upper()`、`.lower()` 等方法

## 名稱對應

| Python 寫法 | 執行期符號 | 說明 |
| --- | --- | --- |
| `print(...)` | `println` | 以空格分隔參數，最後換行 |
| `input(prompt)` | `readline` | 逐行讀取標準輸入 |
| `int(text)` | `parseInt` | 十進位整數字串轉整數 |
| `a.append(x)` | `push` | 就地附加到列表 |
| `a.pop()` | `pop` | 移除並回傳最後一個元素 |
| `x in a` | `contains(a, x)` | 列表成員或子字串檢查 |

## 編碼方式

- **變數**：使用保留色盤中的唯一顏色，無斜體、無底線、無字型。
- **函式呼叫／參數清單**：斜體 `喵` 作為括號，顏色依巢狀深度使用灰階。
- **文字常值**：紫色（`0x7030A0`）加單底線的 `喵` 包住內容；內容為黑色。
- **內建符號**：使用喵語密碼詞（`喵喵`／`喵嗚`／`嗚喵`／`嗚嗚`）加上保留
  的顏色、粗體、雙底線與高亮組合，避免與使用者變數混淆，完全不需要字型。
- **整數字面量**：編譯成 `parseInt("...")`，避開 DOCX 字級上限。

喵語密碼讓任何 Word 都能直接顯示編譯後的 DOCX，不需要安裝字型。舊版
`Meow-*` 字型（`fonts/`，選用）僅適用於早期的字型編碼 DOCX。使用者安裝：

```bash
sh fonts/install-fonts.sh --user
```

Android 系統層（Word 等 App）需要 root 與重新開機：

```bash
su -c 'sh fonts/install-fonts.sh --android-module --yes'
```

字型由 `tools/gen_meow_fonts.py` 產生，詳細說明請見 `fonts/README.md`。

## 建置需求

前端只需要 Python 3.10 以上，沒有額外套件。執行編譯後的 DOCX 需要原生版：

```bash

```

Windows 目前提供 CMake 設定，但尚未在 Windows 上實際驗證；需要
MinGW-w64 或 MSVC，以及 zlib、expat、libpng、libjpeg。
