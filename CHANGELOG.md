# Changelog

This project is a fork of [Glavo/MeowLang](https://github.com/Glavo/MeowLang).
Changes in this fork were developed by **DeepSeek V4.1 Flash**.

## 1.2.0-cipher (2026-10-24)

### Added

- **Meow cipher**: built-ins are encoded with a code word plus formatting
  instead of custom font names, so compiled DOCX files need no fonts.
  - Code words: `喵喵` (I/O), `喵嗚` (math/comparison), `嗚喵`
    (lists/strings), `嗚嗚` (control/syntax).
  - Formatting: 8 colors × bold × double underline × yellow highlight = 64
    combinations, 53 in use (one per built-in).
  - The four `喵` code words plus the 28 multilingual meow words are still
    accepted as symbols.
- `tools/meow_cipher.py`, the single source of truth for the cipher. It
  generates the `g_functions` and `g_macros` tables in `native/meow.c`, and a
  consistency check confirms both sides match.
- Cipher legend in all five README files: 53 rows each, grouped into four
  `<details>` sections, with color, bold, underline, and highlight columns.
- Local badge SVGs for OpenCode, PLCT Lab, and IntelliJ IDEA in `images/`, so
  the README renders offline (the IntelliJ logo is no longer hotlinked).

### Changed

- Parser identity is now formatting-only: `Meow` no longer stores the text of
  a symbol, and built-ins are matched without a font name (`font = NULL`,
  `size = -1`).
- `tools/meowc.py` emits cipher runs instead of `Meow-*` font runs. Its output
  is deterministic: regenerating the examples reproduces the same
  `word/document.xml` byte for byte.
- `install.sh` installs the binary only by default; fonts are opt-in with
  `--fonts`. The old `--no-fonts` flag was removed.
- Native version is now `1.2`; `meowc --version` reports `1.2`.
- All five READMEs were rewritten: full syntax reference, every usage method,
  the cipher legend, the entertainment disclaimer, the visible feline note,
  and updated credits (DeepSeek V4.1 Flash, OpenCode Free API, PLCT Lab as the
  upstream sponsor).

### Fixed

- Double-underline runs are parsed correctly.
- Release packaging now ships `tools/meow_cipher.py` and `images/`; previously
  a repackaged tarball could not run `meowc.py` and its README logos were
  missing.

### Verified

- `native/meow.c` compiles with `-O2 -std=c11 -Wall -Wextra` with zero
  warnings.
- `hello`, `test1`, and a full 2048 session (moves, merges, scoring, quit)
  pass.
- The 53 built-in entries in `native/meow.c` match `tools/meow_cipher.py`
  exactly.
- Cipher tables in all five READMEs match the specification (53 rows, same
  names, colors, and style markers).

## 1.1.1-fonts (2026-10-23)

### Added

- 48 generated `Meow-<name>.ttf` symbol fonts in `fonts/`. Each font maps
  `喵` (U+55B5) to a readable glyph for one built-in symbol, so DOCX files can
  be read without changing their executable text.
- `tools/gen_meow_fonts.py`, a deterministic generator that parses
  `native/meow.c` and composes glyphs from Droid Sans Mono outlines.
- `fonts/install-fonts.sh` with `--user`, `--prefix`, `--android-module`,
  `--uninstall`, `--check`, and `--yes` modes.
- Android system-wide support through a KernelSU/Magisk overlay module that
  adds `/system/fonts/Meow-*.ttf` and appends the matching families to
  `/system/etc/fonts.xml`. A reboot is required.
- `tools/package-release.sh` and a top-level `install.sh` so release tarballs
  contain the fonts and install them automatically for the current user.
- `install-fonts` targets in `native/Makefile` and `native/CMakeLists.txt`.
- Font documentation, notices, and the Apache-2.0 license text.

### Changed

- All five README files, `CREDITS.md`, `CHANGELOG.md`, `native/README.md`, and
  `tools/README.md` now document the symbol fonts, installation, and the
  Apache-2.0 exception for the generated font files.
- Existing same-name fonts are backed up to a timestamped
  `.meow-fonts-backup-*` directory before installation.

### Verified

- The generator produced 48 fonts; `fontTools` validated the family name,
  PostScript name, U+55B5 cmap entry, and advance width for every font.
- Termux user installation: 48 / 48 fonts present; `--check` passes.
- The native binary and the 2048 example were rebuilt and re-tested after the
  integration.

## 1.1.0-native (2026-10-23)

### Added

- Python-style frontend compiler: `tools/meowc.py`.
  - Compiles readable `.meow` source into the same styled `.docx` format.
  - The runtime remains the native C11 interpreter; no Java is involved.
  - Supports variables, assignment, augmented assignment, arithmetic,
    comparisons, `if`/`elif`/`else`, `while`, `for` over lists and text,
    functions, recursion, early `return`, list literals, indexing, slices,
    `append`, `pop`, strings, `in`, `and`/`or`/`not`, and conditional
    expressions.
  - Uses `builtin_ident` markers so user variables cannot shadow internal
    calls generated by the compiler.
- Native control-flow macros: `if`, `while`, `for`, `do`, and `return`.
  - `return` is implemented with `setjmp`/`longjmp` for early function exit.
  - `and` and `or` short-circuit.
- Native built-in functions for arithmetic, comparison, lists, strings, random
  numbers, and terminal clearing.
- Playable text-mode 2048: `examples/game2048.meow`.
- Example programs: `hello.meow`, `test1.meow`, and `game2048.meow`.
- Portable build files:
  - `native/Makefile` uses `pkg-config` when available and falls back to
    `-lz -lexpat -lpng -ljpeg`.
  - `native/CMakeLists.txt` supports Linux, Android/Termux, and a Windows
    build configuration (MinGW-w64 or MSVC; not yet tested on Windows).
- Documentation for the frontend, examples, and native build.

### Changed

- Native version is now `1.1`.
- `print` keeps the original newline-separated argument semantics;
  `println` uses space separators for Python-style output.
- `/` and `//` both perform integer division rounded toward negative infinity.
- Integer literals produced by the frontend are encoded as
  `parseInt("...")` to avoid DOCX font-size limits.
- New built-in symbols use the `Meow-<name>` font, color `0x404040`, and no
  highlight, so they cannot collide with user-defined symbols.
- Removed POSIX-only helpers from the native source (`strtok_r`,
  `strcasecmp`, `<unistd.h>`) to improve portability.

### Verified

- `examples/test1.meow` passes arithmetic, integer division, `if`/`elif`/`else`,
  `while`, `for`, functions, recursion, early return, lists, slices, strings,
  `in`, `and`/`or`/`not`, and conditional expressions.
- `examples/game2048.meow` runs with piped moves (`a`, `d`, `w`, `s`, `q`) and
  produces a correct board, merges, score, and exit.
- `demo/HelloWorld.docx` output is byte-for-byte identical to the previous
  native binary (including ANSI sequences).
- Native full demo run: about 0.024 seconds on Termux/Android aarch64
  (50 runs). Binary size: about 56 KB.

## 1.0.0-native (2026-10-23)

### Added

- Native C implementation `native/meow`; no JVM required.
- Self-contained ZIP reader for stored (method 0) and deflate (method 8)
  entries.
- expat parsing of `word/document.xml` and
  `word/_rels/document.xml.rels`.
- DrawingML embedded images decoded with libpng and libjpeg, rendered as ANSI
  half-block characters.
- Bold, italic, underline, color, highlight, font, and font-size support.
- Unicode case conversion for ASCII, Latin-1, Greek, and Cyrillic, including
  `Мяу` and `Μιάου`.
- Integers can be used as index functions: applying integer `n` to an argument
  list returns the `n`-th argument.
- `MEOW_DEBUG=1` prints the parsed expression and evaluation trace.
- `--version` and `--help` command-line options.
- README files in English, Traditional Chinese, Simplified Chinese, Japanese,
  and Korean.
- `CREDITS.md`, `CHANGELOG.md`, and `native/README.md`.

### Changed

- The native implementation is now the recommended runtime; the Java version
  remains as a reference implementation.
- README files are multilingual and identify DeepSeek V4.1 Flash as the fork
  developer.

### Verified

- `demo/HelloWorld.docx`: text output matches the Java version (byte-for-byte
  after removing ANSI sequences).
- `play/card.docx`: text output matches the Java version, including integer
  index selection of card styles.
- Performance on Termux/Android aarch64:
  - `demo/HelloWorld.docx`: Java about 0.42 s, native about 0.03 s.
  - `play/card.docx`: Java about 0.37 s, native about 0.03 s.
  - Python 3.13.13 comparison (30 runs):
    - Startup only: 0.050 s.
    - Decompress `word/document.xml` only: 0.084 s.
    - Native full demo: 0.027 s (ZIP, XML, evaluation, PNG, and ANSI output).
    - Native `--version`: 0.018 s.

## 0.2.0-java (2026-10-23)

### Changed

- Replaced Apache POI with `MeowDocxReader` (`ZipFile` + StAX).
- Added lightweight `MeowRun`, `MeowHighlight`, and `MeowUnderline` models.
- Removed `poi-ooxml` and `log4j-core` dependencies.
- JLine is loaded lazily; non-interactive mode does not load JLine.
- Reduced the JAR from about 22.6 MB to about 1.5 MB.
- Reduced `demo/HelloWorld.docx` startup time from about 1.7 s to about 0.42 s.

## 1.1.0-native（2026-10-23）

### 新增

- Python 風格前端編譯器 `tools/meowc.py`，將 `.meow` 編譯成喵樣式 `.docx`；
  執行期仍是原生 C11 解譯器，不依賴 Java。
- 支援變數、指派、複合指派、算術、比較、`if`／`elif`／`else`、`while`、
  對列表與文字使用 `for`、函式、遞迴、提前 `return`、列表、索引、切片、
  `append`、`pop`、字串、`in`、`and`／`or`／`not` 與三元運算式。
- 原生控制流程巨集：`if`、`while`、`for`、`do`、`return`；`return` 以
  `setjmp`／`longjmp` 實作。
- 原生內建函式：算術、比較、列表、字串、隨機數與清除終端機。
- 可玩的文字版 2048：`examples/game2048.meow`。
- 範例程式：`hello.meow`、`test1.meow`、`game2048.meow`。
- 可攜建置：`Makefile` 優先使用 `pkg-config`，`CMakeLists.txt` 支援
  Linux、Android/Termux 與 Windows 建置設定（Windows 尚未實測）。
- 新增前端、範例與原生建置文件。

### 變更

- 原生版版本改為 `1.1`。
- `print` 保留原本以換行分隔參數的語意；`println` 改用空格分隔。
- `/` 與 `//` 都是整數除法，向負無限方向取整。
- 前端產生的整數字面量改用 `parseInt("...")` 編碼。
- 新內建符號使用 `Meow-<name>` 字型、顏色 `0x404040`、無螢光標記。
- 移除原生原始碼中的 POSIX 專用輔助函式（`strtok_r`、`strcasecmp`、
  `<unistd.h>`），提升可攜性。

### 驗證

- `examples/test1.meow` 通過算術、整數除法、`if`／`elif`／`else`、`while`、
  `for`、函式、遞迴、提前返回、列表、切片、字串、`in`、`and`／`or`／`not`
  與三元運算式測試。
- `examples/game2048.meow` 以管線輸入 `a`、`d`、`w`、`s`、`q` 執行成功，
  棋盤、合併、計分與離開均正常。
- `demo/HelloWorld.docx` 輸出與前一版原生執行檔逐位元組相同（含 ANSI）。
- Termux／Android aarch64 完整執行 demo 約 0.024 秒（50 次平均），
  執行檔約 56 KB。
